# 📞 How Long We Talked

여자친구와 통화한 기록을 가지고 **우리는 얼마나 오래 통화했을까?** 를
알아보기 위해 만든 간단한 R 프로젝트.

통화 기록의 `시:분:초` 데이터를 초 단위로 변환하고, 여러 통계량을
계산해봤습니다.

## 🧐 What I Found

평균 통화시간은 약 **43분 14초**이지만 중앙값은 약 **18분 36초**으로 꽤
큰 차이가 있습니다.

제1사분위수(Q1)는 3분 42초, 제3사분위수(Q3)는 50분 20초로, 통화시간의
가운데 50%가 약 **3분 42초 \~ 50분 20초** 사이에 분포합니다.

또한 왜도가 **5.3583858**으로 양의 왜도를 보이고 있어, 대부분의 통화는
비교적 짧지만 일부 매우 긴 통화가 존재하는 형태로 보입니다.

실제로 가장 긴 통화는 **18시간 29분 0초**였습니다.

표준편차도 **1시간 11분 34초**로 평균 통화시간보다 크고, 변동계수(CV)
역시 **165.5419287%** 로 나타나 통화시간의 변동이 상당히 큰 것을 확인할
수 있었습니다.

하루 평균으로는 약 **3시간 30분 52초**을 통화했고, 하루 평균 통화 횟수는
약 **4.88회**였습니다.

일일 통화 횟수와 일일 총 통화시간의 상관계수는 **0.4407029**로, 통화
횟수가 많은 날일수록 총 통화시간도 늘어나는 경향이 있었습니다.

반면 일일 통화 횟수와 일일 평균 통화시간의 상관계수는 **-0.2360464**로
약한 음의 상관관계를 보였습니다.

즉, 통화를 많이 하는 날에는 한 통화당 평균 시간은 조금 짧아지는 경향이
있었습니다.

상관계수는 두 변수의 선형적인 관계를 나타내며, 인과관계를 의미하지는
않습니다.

하루에 가장 많이 통화한 날에는 **13**이나 전화를 했고, 가장 오래 통화한
날에는 하루 동안 총 **20시간 14분 6초**를 통화했습니다.

그리고...

> **약 27일 9시간 14분 3초가 넘도록 통화했다.**

생각보다 많이 했다.
