# 📞 How Long We Talked

여자친구와 통화한 기록을 가지고 **우리는 얼마나 오래 통화했을까?** 를 알아보기 위해 만든 간단한 R 프로젝트.

## 🧐 What I Found

평균 통화시간은 약 **45분**이지만 중앙값은 약 **19분**으로 꽤 큰 차이가 있습니다.

몇 번의 긴 통화가 평균을 상당히 끌어올리고 있는 것으로 보입니다.

하루에 가장 많이 통화한 날에는 13번이나 전화를 했고,
가장 오래 통화한 날에는 하루 동안 총 11시간 42분 54초를 통화했습니다.

그리고 가장 긴 통화는 7시간 12분 51초였습니다.

그리고...

> **15일이 넘도록 통화했다.**

생각보다 많이 했다.
