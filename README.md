# 📞 Call Time Analyzer

여자친구와 통화한 기록을 가지고 **우리는 얼마나 오래 통화했을까?**를 알아보기 위해 만든 간단한 R 프로젝트.

통화 기록의 `시:분:초` 데이터를 초 단위로 변환하고, 여러 통계량을 계산해봤습니다.

## 📊 Statistics

- 총 통화 횟수: **500회**
- 총 통화 시간: **378시간 25분 14초**
- 평균 통화 시간: **45분 24초**
- 중앙값: **19분 26초**
- 가장 긴 통화: **7시간 12분 51초**
- 가장 짧은 통화: **1초**
- 누적 통화 시간: **약 15일 18시간 25분 14초**

## 🧐 What I Found

평균 통화시간은 약 **45분**이지만 중앙값은 약 **19분**으로 꽤 큰 차이가 있습니다.

몇 번의 긴 통화가 평균을 상당히 끌어올리고 있는 것으로 보입니다.

그리고...

> **15일이 넘도록 통화했다.**

생각보다 많이 했다.
